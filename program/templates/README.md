# Templates

> [!NOTE]
> **🧭 Guide.** Reusable records for recurring and event-driven controls. Copy a template into the evidence folder for that control and period (for example `evidence/2026-Q1/AC-03A/access-review.md`), or into the ticket or tool where the work happens, then fill it in and link it from the matching row in [activity-log.csv](../records/activity-log.csv), [people.csv](../registers/people.csv) or [requests-and-tickets.csv](../records/requests-and-tickets.csv). Record what actually happened, when and by whom; never back-date a record.

| Template | Controls | When |
| --- | --- | --- |
| [Access review record](access-review-record.md) | AC-03A, AC-05A | Quarterly |
| [Management review minutes](management-review-minutes.md) | GV-02B, RM-02A | At the agreed rhythm |

| [Vendor review](vendor-review.md) | VM-01A, VM-02, VM-03, VM-05A | Before onboarding, then by tier |
| [Onboarding checklist](onboarding-checklist.md) | HR-01, HR-02, HR-03, AC-01A, AC-07, GV-06 | Each new starter |
| [Leaving checklist](leaving-checklist.md) | AC-02, EP-04 | Each leaver |
| [Incident record](incident-record.md) | IR-03 | Each incident |
