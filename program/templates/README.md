# Templates

> [!NOTE]
> **🧭 Guide.** Records and procedures for the recurring and event-driven controls, drafted for the reference company. Copy a template into the evidence folder for that control and period (for example `evidence/2026-Q1/AC-03A/access-review.md`), or into the tool where the work happens, then fill it in and link it from [activity-log.csv](../records/activity-log.csv), [people.csv](../registers/people.csv) or [requests-and-tickets.csv](../records/requests-and-tickets.csv). The [control calendar](../plans/control-calendar.md) says when each recurring one is due. Record what actually happened; never back-date a record.
