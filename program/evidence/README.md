# Evidence

> [!NOTE]
> **🧭 Guide.** One folder per audit period, one subfolder per control ID, named so the occurrence and date are obvious (AI Guidance 7.3). Each item is the minimum that proves the control operated: the approval, the completed review, the configuration at a point in time (4.4). See the [evidence guide](../plans/evidence-guide.md).

```
evidence/
  2026-Q1/
    AC-03A/  2026-03-14 access review.md
    AC-07/   2026-02-02 MFA enforcement setting.png
```

> [!WARNING]
> Keep this repository private. Never store passwords, keys, tokens, customer content, health information or unnecessary personal data here. If your evidence is large or sensitive, keep it in your file storage and put the link in the control list instead.
