# Your controls

> [!NOTE]
> **🧭 Guide.** The control list is what you'll be audited on and collect evidence for. Generate it early, before policies or registers (AI Guidance 8.1), and tie everything else back to it: every policy statement, risk, vendor review, template, recurring activity and evidence folder names the control IDs it supports (8.3).

| File | What it is |
| --- | --- |
| [scope.md](scope.md) | Generated by `python3 tools/scope.py` from your profile. Lists the in-scope controls with wording tailored to your tools, plus the policies, statements and risks they bring in. Don't edit it; change the profile and run the tool again. |
| [control-list.csv](control-list.csv) | Your working list: one row per in-scope control. It's your to-do list and dashboard. |

## Control list columns

The list ships with the reference company's 75 controls, so you can see a complete first cut. Your agent re-runs the scope tool on your profile and adds, swaps or removes rows to match (see [what-else-to-add.md](../what-else-to-add.md)).

| Column | What to put |
| --- | --- |
| ID | The control ID from the library, such as AC-03A |
| Control | The control name |
| What we do | The control wording, with tool variables such as `{{identity provider: Google Workspace}}` |
| Owner | The role who runs it (CEO, CTO, Head of Operations, Lead Engineer in the reference company) |
| Frequency | Annually, Quarterly, Configuration, Event-driven and so on |
| Where it lives | The system or record where the control operates |
| Evidence | What proves it worked: an approval, a completed review, a configuration screenshot (4.4) |
| Policy | The policy that covers it |
| Template | The template in [program/templates/](../templates/) that records it, if any |
| Status | `Gap`, `Designed`, `Operating`, `Evidence ready` or `Not applicable` |
| Last operated / Next due | Dates, for recurring controls; the [control calendar](../plans/control-calendar.md) suggests months |
| Evidence link | The evidence folder for this control and period |
| Notes | Anything open |

> [!IMPORTANT]
> **✏️ Adapt.** 🤖 AI: replace the example rows with every control in scope.md, set Frequency and Evidence source from the library, and mark each Gap, Designed or Operating from what you can see. If an answer conflicts with an in-scope control (for example no scanning tool while vulnerability scanning is in scope), mark it Gap and raise it (8.5). 👤 Owners: confirm each row you own.

When a control comes into or drops out of scope, tell the Compliance Owner and log it in the audit trail (8.4).
